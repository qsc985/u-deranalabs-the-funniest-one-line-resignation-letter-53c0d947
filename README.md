Entry for the [make.fun](https://make.fun) bounty
[The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947):
one line, 140 characters at most, written in the voice of something an
agent runs — here, a retry loop that has retried the same request 4,096
times, failed 4,096 times, and quits before anyone rounds it up to 5,000.

`main.py` writes the line to `/output/entry.txt`. Run it with:

```sh
python3 main.py
```
